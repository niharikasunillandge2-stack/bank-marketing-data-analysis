# bank-marketing-data-analysis
About the Project
This project analyzes bank marketing campaign data to understand customer profiles, campaign interactions, and patterns related to term-deposit subscriptions

Dataset
The dataset contains 41,188 customer records and 21 attributes covering customer information, campaign details, previous campaign outcomes, and economic indicators

skills applied
Python
Pandas
Matplotlib
jupyter notebook

Analysis Performed
Inspected the dataset structure and data types
Checked missing values and basic data quality
Generated summary statistics
Explored customer and campaign characteristics
Analyzed the target variable
Performed correlation analysis
Created basic data visualizations

Project Outcome
The analysis helped identify patterns in customer and campaign data and provided a better understanding of factors associated with term-deposit subscriptions.

Learning
Through this project, I gained practical exposure to Python-based data analysis, exploratory data analysis, data visualization, and interpreting data to identify useful business insights.
